# Skills the model may not invoke on its own; you have to type the slash command.
#
# The default here is the opposite of the usual one: a skill is model-invocable unless it
# is named below. These seven are named because each mutates something outside the working
# tree, so an invocation the user did not ask for costs more than a round trip. `sync`
# force-pushes, so an unasked-for run can also rewrite a branch someone else is reading,
# `wire-up` pulls two repos and rewires the whole machine's setup, and `address-review-loop` spends
# rounds of agents committing and pushing to a branch until a review approves it.
#
# A skill listed here carries no "Use when ..." clause in its description. The model never
# sees the description of a skill it may not invoke, so the clause would name triggers for a
# reader that cannot act on them. What stays is what the skill does, which is what you read
# in the slash menu when you pick it yourself.
#
# `commit` is deliberately absent. Its PreToolUse hook blocks `git commit` itself, which is
# strictly stronger than blocking the skill that wraps it, and making it explicit-only would
# stop open-pr and address-review from following it as a step.
#
# The validator holds this list, SKILL.md's `disable-model-invocation` and
# agents/openai.yaml's `policy.allow_implicit_invocation` to the same answer, so a skill
# cannot end up explicit-only in one runtime and automatic in the other.
address-review
address-review-loop
land
open-pr
sync
todo
wire-up
